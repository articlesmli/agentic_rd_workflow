## Overview

**agentic_rd_workflow** is a resilient, graph-based agentic pipeline for processing dense R&D documents and clinical trial protocols. It is built around a cyclical **Extract → Validate → Correct → Re-evaluate** loop rather than a brittle linear pipeline, with optional on-demand Model Context Protocol (MCP) tool integration for external lookups (e.g. hospital site compliance checks).

### Tech stack

- **LangGraph** — state orchestration and cyclical correction/validation flow
- **Pydantic AI** — typed, production-grade LLM agents with structured output enforcement
- **FastAPI** / **Uvicorn** — asynchronous REST API layer
- **MCP (FastMCP)** — optional dynamic tool execution for external data lookups
- **OpenAI** API as the underlying LLM provider
- **Pytest** for testing, **Ruff** for linting (per CI config)
